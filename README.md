# pdf2md.mcp

`pdf2md.mcp` is intended to provide PDF-to-Markdown conversion through the
Model Context Protocol (MCP).

## Project Status

This repository is in its initial documentation stage. No conversion engine,
MCP server, implementation language, runtime architecture, or supported release
has been established. There is currently no executable to build or run and no
automated test suite.

Setup prerequisites, source layout, configuration, and build, run, and test
commands will be documented here with the first implementation.
